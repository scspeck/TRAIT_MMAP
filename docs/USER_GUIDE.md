# Trait MMAP user guide

## 1. Upload
Choose a CSV containing geographic coordinates and the biological variables you want to explore.

## 2. Configure fields
Assign latitude and longitude, then map useful identifiers, taxonomy, geography, dates, and other descriptive fields. Additional columns can be classified as numeric, categorical, or text traits.

## 3. Filter
Categorical filters support multiple simultaneous values. Open a categorical filter to scroll through its values or type in **Search values** to narrow the menu. The search box changes only the choices displayed in the menu; it does not itself filter map records. Check the values you want included.

Numeric traits support exact, minimum, and maximum criteria. Text traits support field-specific text searching.

## 4. Explore
Build the map and inspect the filtered distribution. Left-click a point to inspect its record. Right-click a point to select or deselect it.

## 5. Select
Use individual points, rectangles, or polygons to create spatial subsets from currently eligible records.

## 6. Export
Export filtered or selected records as CSV for tabular/statistical workflows or GeoJSON for spatial/GIS workflows.

## Interpretation
Trait MMAP is an exploratory mapping and subsetting tool. It does not correct source-data errors, sampling bias, georeferencing uncertainty, or taxonomic inconsistencies, and mapped record density should not automatically be interpreted as biological abundance.
